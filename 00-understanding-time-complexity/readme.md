# Algorithms, Time Complexity, and Space Complexity

## 1. What Is an Algorithm?

An **algorithm** is a step-by-step set of instructions used to solve a problem or complete a task.

For example, finding the first element of an array is an algorithmic operation.

```javascript
function getFirst(arr) {
  return arr[0];
}
```

## 2. What Is Time Complexity?

**Time complexity** describes how the number of operations performed by an algorithm grows as the input size increases.

It does not measure the exact execution time in seconds. Instead, it describes the growth rate of the algorithm's work.

For example, an algorithm that processes every element in an array generally performs more operations as the array grows.

## 3. What Is Space Complexity?

**Space complexity** describes how the memory requirements of an algorithm grow as the input size increases.

In this lesson, we focus on **auxiliary space**, which means the additional memory used by an algorithm, excluding the input itself.

For example, creating a new array to store `n` elements requires additional memory that grows with `n`.

## 4. Common Time and Space Complexity Patterns

| Code Pattern | Time Complexity | Auxiliary Space | Why? |
|---|---|---|---|
| `arr[0]` | `O(1)` | `O(1)` | One indexed access with no additional memory proportional to input size. |
| `for (let i = 0; i < n; i++)` | `O(n)` | `O(1)` | Executes `n` iterations using a constant number of variables. |
| Two sequential loops of `n` iterations | `O(n)` | `O(1)` | Total iterations are `n + n = 2n`, which simplifies to `O(n)`. |
| Two nested loops of `n` iterations each | `O(n²)` | `O(1)` | Total iterations are `n × n = n²`; the loops use constant extra memory if they do not store results. |
| Nested loop with an inner limit of `5` | `O(n)` | `O(1)` | Total iterations are `n × 5 = 5n`, which simplifies to `O(n)`. |
| Creating an array of `n` elements | `O(n)` | `O(n)` | The algorithm processes and stores `n` additional elements. |
| Storing all pairs generated by two nested loops | `O(n²)` | `O(n²)` | The algorithm creates and stores `n × n` pairs. |

**Note:** These space complexities assume that the input is excluded from auxiliary space and that no other memory-intensive operations occur.

## 5. Understanding Big O Notation

Big O notation describes how an algorithm's resource usage grows as the input size increases.

### A. O(1) — Constant Time

The number of operations stays approximately constant as the input size grows.

```javascript
function getFirst(arr) {
  return arr[0];
}
```

- Time complexity: `O(1)`
- Auxiliary space: `O(1)`

**Why?** The function accesses only one element and does not create additional storage that grows with the input.

### B. O(n) — Linear Time

The number of operations grows proportionally to the input size.

```javascript
function printNumbers(n) {
  for (let i = 0; i < n; i++) {
    console.log(i);
  }
}
```

- Time complexity: `O(n)`
- Auxiliary space: `O(1)`

**Why?** The loop executes `n` times, but only a constant number of variables is needed.

### C. O(n²) — Quadratic Time

The number of operations grows proportionally to the square of the input size.

```javascript
function printPairs(n) {
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      console.log(i, j);
    }
  }
}
```

- Time complexity: `O(n²)`
- Auxiliary space: `O(1)`

**Why?** The inner loop runs `n` times for every iteration of the outer loop, resulting in `n × n = n²` operations.

**Important:** Nested loops do not automatically mean `O(n²)` space complexity. In this example, the pairs are printed rather than stored.

## 6. Understanding Space Complexity with Examples

### A. O(1) — Constant Space

```javascript
function sumNumbers(n) {
  let sum = 0;

  for (let i = 0; i < n; i++) {
    sum += i;
  }

  return sum;
}
```

- Time complexity: `O(n)`
- Auxiliary space: `O(1)`

**Why?** The function uses only a few variables, regardless of how large `n` becomes.

### B. O(n) — Linear Space

```javascript
function createArray(n) {
  const result = [];

  for (let i = 0; i < n; i++) {
    result.push(i);
  }

  return result;
}
```

- Time complexity: `O(n)`
- Auxiliary space: `O(n)`

**Why?** The function creates an array containing `n` elements. As `n` grows, the additional memory grows proportionally.

### C. O(n²) — Quadratic Space

```javascript
function storePairs(n) {
  const pairs = [];

  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      pairs.push([i, j]);
    }
  }

  return pairs;
}
```

- Time complexity: `O(n²)`
- Auxiliary space: `O(n²)`

**Why?** The function stores `n × n` pairs in an array, so the amount of additional memory grows quadratically.

## 7. Measured Execution Time vs. Time Complexity

These concepts are related but different.

| Measured Execution Time | Time Complexity |
|---|---|
| Measures how long code takes to run. | Describes how the amount of work grows with input size. |
| Usually measured in milliseconds or seconds. | Expressed using Big O notation, such as `O(1)` or `O(n)`. |
| Can vary with hardware, browser, and system load. | Focuses on growth as the input size increases. |
| Can be measured with `console.time()` and `console.timeEnd()`. | Is analyzed from the algorithm's operations. |

Example:

```javascript
console.time("execution");

for (let i = 0; i < 1000000; i++) {
  // Perform an operation
}

console.timeEnd("execution");
```

This measures the execution time for a particular run. The loop has `O(n)` time complexity because its number of iterations grows linearly with `n`.

## 8. Rules for Analyzing Loops

1. A single loop running `n` times generally has `O(n)` time complexity.
2. Two sequential loops running `n` times each have `O(n)` time complexity because `O(n + n) = O(n)`.
3. Two nested loops running `n` times each generally have `O(n²)` time complexity.
4. If an inner loop runs a fixed number of times, such as `5`, the total remains `O(n)`.
5. A loop does not necessarily increase auxiliary space if it uses only a constant number of variables.
6. Creating and storing data can increase space complexity even if the loop structure stays the same.

## 9. Quick Reference

| Complexity | Name | Typical Example |
|---|---|---|
| `O(1)` | Constant | Accessing `arr[0]` |
| `O(n)` | Linear | Processing every element |
| `O(n²)` | Quadratic | Comparing every pair using two nested loops |

## 10. Key Takeaways

- An algorithm is a step-by-step procedure for solving a problem.
- Time complexity describes how the amount of work grows with input size.
- Space complexity describes how memory usage grows with input size.
- Measured execution time is not the same as time complexity.
- Ignore constant factors when simplifying Big O: `O(2n) = O(n)` and `O(5n) = O(n)`.
- Analyze time and auxiliary space separately.
- Nested loops may increase execution time without increasing auxiliary space.
